# 1H 关键价位热力图（1H Key Level Heatmap）

TradingView Pine Script v6 指标，由 **NeuNue** 开发，主要基于 **QQQ** 校准。

自动识别美股大盘股与高流动性 ETF 的关键支撑 / 阻力，并把统计上相近的价位合并为带强度的“关键价位区间”，像热力图一样叠加在图表上。

> **适合谁**：基于关键价位回踩后做**右侧交易**的交易者。
>
> **不适合谁**：预设关键价位有效、提前在支撑位挂限价单抄底的**左侧交易**者。

---

## ✨ 功能特性

- **固定 1 小时 RTH K 线**：所有证据都来自 1 小时常规交易时段，图表周期支持 1 分钟～1 小时，无论用什么周期看盘，底层逻辑一致。
- **五类证据加权打分**：触及与拒绝 / 多空转换 / 相对成交量 / 缺口 / 整数共振，每类证据独立权重。
- **双重时间衰减**：短期与长期证据按交易日衰减，老旧的支撑阻力自然淡出。
- **不随 tick 重绘**：v1.1.0 起证据只取自已收盘的 1H K 线，价位与强度只在整点收盘后更新（形成中的 1H K 线事件滞后最多约 1 小时计入）。
- **上下方各占一半名额**：最多显示 12 个区间，上方与下方分别保留一半名额，避免图面一边倒。
- **最小显示间距**：距离过近的区间只保留分数更高者，减少相邻价位的干扰。
- **热力显示**：颜色深浅表示可交易性分数，右侧标签显示 中心价 | 分数。

## 🚀 快速开始

1. 打开 [key_level_heatmap.pine](key_level_heatmap.pine)，复制全部内容；
2. 在 TradingView 打开 Pine 编辑器，粘贴，点击“添加到图表”；
3. 图表周期选择 **1 小时及以下**（1 分钟～1 小时均可，指标内部固定使用 1 小时数据）；
4. 适用标的：QQQ、SPY、SOXX，以及 AAPL、MSFT、NVDA 等成交活跃的大盘股。小盘股、低流动性标的、外汇、加密货币、全天交易期货适配度较低。

## 🎛 参数说明

### 核心设置

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 灵敏度 | 标准 | 保守 / 标准 / 密集三档，控制枢轴腿数、冷却 K 线数、缺口与放量阈值 |
| 最大区间数 | 8 | 图上同时显示的高强度区间数量上限（4～12） |
| 最低强度 | 35 | 可交易性分数低于该值的区间不显示（0～100） |
| 邻近区间合并距离（ATR） | 0.75 | 显示前按 1H ATR 合并相邻微区间，数值越大区间越少、覆盖越宽 |
| 最小显示间距（ATR） | 1.25 | 已显示区间中心之间的最小距离，太近只保留分数更高者；设为 0 禁用 |
| 区间宽度 | 标准 | 窄 / 标准 / 宽，宽度由事件发生时的 1H ATR 决定 |

### 整数位置

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 整数步长 | 自动 | 自动按标的价格选择整数网格，或切换为手动 |
| 手动基础步长 | 5 | 仅在“手动”模式生效 |

### 显示设置

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 显示中心线 | ✅ | 中心线用于与人工标注价位对比，热力区间本身才是有效范围 |
| 显示价位与强度 | ✅ | 右侧标签格式：中心价 | 可交易性分数 |
| 标签字号 | 中 | 小 / 中 / 大，看不清时可调大 |
| 最大显示距离（ATR） | 12 | 隐藏距离现价过远的历史区间 |
| 热力颜色 | 蓝紫 | 颜色只表达关键性强弱，不表达方向 |

### 高级权重

| 权重 | 默认 | 含义 |
| --- | --- | --- |
| 触及与拒绝 | 40 | 这个位置以前有没有被机构资金防守过 |
| 多空转换 | 20 | 阻力突破后变支撑 / 支撑跌破后变阻力 |
| 相对成交量 | 20 | 关键位置形成时，参与交易的人是否明显比平时多 |
| 缺口 | 10 | 开盘跳空留下的上下边界 |
| 整数共振 | 10 | 700、705、710 这类容易被挂单的整数位 |

> 权重是**相对权重**，不要求加起来等于 100：全部同时乘以两倍不改变结果，把某项设为 0 才表示完全不考虑这一类证据。

## ⚖️ 三套参考配置

权重顺序：触及拒绝 / 多空转换 / 相对成交量 / 缺口 / 整数共振。

| 配置 | 权重 | 适合 |
| --- | --- | --- |
| 均衡型（默认） | 40 / 20 / 20 / 10 / 10 | QQQ 调教配置；指数 ETF、成交活跃的大盘科技股；盘中观察与波段交易 |
| 传统支撑阻力型 | 50 / 25 / 15 / 5 / 5 | 走势稳定、历史价位反复有效的 SPY / 成熟大盘股；区间或均值回归交易 |
| 事件与缺口型 | 30 / 15 / 25 / 20 / 10 | 财报反应明显、消息驱动强的成长型大盘股；不建议小盘消息股 |

## 🛠 调整指南

- 建议从默认值开始，每次只改一项、每次调整 5–10 点；先观察误判漏判属于哪一类，再改对应权重，不要为了贴合一段历史一次性改所有参数。
- 杂乱弱位太多：提高“触及与拒绝”或“最低强度”。
- 突破回踩位经常漏掉：提高“多空转换”。
- 放量形成的价位不够突出：提高“相对成交量”。
- 财报或消息面缺口边界不够突出：提高“缺口”。
- 整数位太多或太少：降低或提高“整数共振”。
- 相邻关键区间太近、互相干扰：提高“最小显示间距（ATR）”。
- 右侧标签数字看不清：在“显示设置”里调大“标签字号”。

## 🧭 推荐用法

1. 把它当作**支撑阻力地图**：以已经收盘并确认的 1 小时区间为主；
2. 盘中结合 **5 分钟 K 线**的价格行为决定是否进场；
3. 不要仅凭当前小时内刚出现或分数正在变化的区间自动下单；
4. 不建议当作历史进场信号回测（中枢高低位需要后续几根 K 线确认）。

## ⚠️ 风险声明

- 数据仅供参考，不适用于实时交易，**不构成投资建议**。
- v1.1.0 起，价位与强度只在 1 小时 K 线收盘后更新，不再随盘中 tick 重绘；正在形成的 1H K 线事件滞后到收盘后计入（最多约 1 小时）。
- 脚本没有使用 lookahead 读取未来数据，但仍不建议当作历史进场信号回测。
- 它不是量化交易工具，只辅助实时观察与回溯研究。
