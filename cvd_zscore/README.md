# CVD Z-Score（累积成交量差值 Z 分数）

TradingView Pine Script v6 副图指标，由 **NeuNue** 开发。用 Z 分数衡量买卖压力（成交量差值 CVD）的强弱与偏离程度，帮助识别资金吸筹、派发、衰竭与量价背离，可作为量价共振分析的辅助工具。本指标为**纯信号版本**：只输出信号与状态，不含任何交易指引（无标签、无止损建议、无策略代码）。

## 📖 简介

CVD（Cumulative Volume Delta，累积成交量差值）把每根 K 线的买盘量减卖盘量逐根累加，是衡量买卖双方真实力量对比的常用指标。但原始 CVD 是累计量，数值会随标的价格与图表起始时间变化，难以直接比较。

本指标把 CVD 换算成 **Z 分数**（当前值与 N 期均值的偏离量 ÷ 标准差），让不同标的、不同周期下的读数可以横向比较：

- **Z 分数 > 0**：买盘占优（多头施压）
- **Z 分数 < 0**：卖盘占优（空头施压）
- **|Z 分数| > 2**：进入极端区，行情可能过热或超卖

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| CVD Z 分数 | 标准化买卖压力动量读数，支持 EMA / SMA / WMA 三种平滑方式 |
| 效率分析（Effort vs Result） | 对比“价格变动”与“CVD 变动”，区分**放量突破**（高性价比上涨/下跌）与**高换手震荡**（低效消耗） |
| 现货吸筹信号 | CVD 持续上升而价格横盘（蓝色圆点），常见于主力低位吸筹 |
| 极限区 / 衰竭预警 | Z 分数进入 ±2 以上极端区（菱形 + 背景高亮），提示过热 / 超卖 |
| 量价背离 | 仅在**枢轴高 / 低点**确认时评估：价格创新高而 CVD 未跟上（**顶背离**，红色 ×），或价格创新低而 CVD 不再走低（**底背离**，绿色 ×） |
| 信号过滤 | 吸筹 / 极限信号只在“入场第一根”触发并带冷却期；背离基于枢轴结构识别；信号默认在 K 线收盘后确认，大幅减少连续重复与盘中重绘 |
| 波动率风格过滤 | 回测显示背离在低波动慢牛上失效：ATR/收盘价 低于阈值的标的上自动抑制吸筹与背离信号 |
| 更高周期（HTF）过滤 | 用上一根已完成的更高周期 Z 分数做方向确认，避免逆大级别追单 |
| 内置仪表盘 | 实时显示 Z 分数、效率状态、阶段（吸筹 / 衰竭 / 中性）、背离状态与**过滤器状态**（6 行） |
| 全套警报 | 吸筹、极限区、穿越零轴、背离等 7 类条件均可设置 Alert（均为收盘确认信号） |

> 📊 **设计依据**：波动率过滤 / HTF 过滤来自 A 股多元回测研究（6 标的 × 5/15/60 分钟 × 2020-2026）：15 分钟周期最稳健、低波动标的失效、止损可显著收窄回撤（止损保护作用已被验证，使用者可自行结合止损 / 仓位规则执行）。

## 🚀 快速开始

**纯信号版（[`cvd_zscore.pine`](cvd_zscore.pine)）**
1. 复制全部内容，在 TradingView Pine 编辑器粘贴，点击“添加到图表”即可观察信号；
2. 适用标的：主流加密货币，以及 A股资产；
3. 推荐周期：15 分钟或 1 小时（回测最稳健）。

## 🎛 参数说明

### Z 分数设置

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| Z 分数回看周期 | 20 | 计算均值与标准差所用的 K 线数；越大越平滑、反应越慢 |
| 平滑长度 | 5 | 对原始 Z 分数做平滑的窗口长度 |
| 平滑方式 | EMA | EMA / SMA / WMA 三选一 |
| CVD 计算方法 | 比例法 | **比例法**：按收盘价在高低范围内的相对位置分摊成交量，最接近真实买卖流（推荐）；**方向法**：只看收阳 / 收阴，十字星记 0；**Elder 法**：经典累积 / 派发线（accdist） |

### 信号设置

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 显示现货吸筹信号 | ✅ | 副图底部蓝色圆点（入场第一根 + 冷却后触发） |
| 显示极限区（衰竭）预警 | ✅ | 菱形 + 背景高亮（菱形为入场第一根 + 冷却后触发） |
| 显示量价背离信号 | ✅ | 红色 ×（顶背离）/ 绿色 ×（底背离），枢轴确认后触发 |
| 极限区上阈值（+） | 2.0 | Z 分数高于该值进入超买 / 衰竭区 |
| 极限区下阈值（-） | -2.0 | Z 分数低于该值进入超卖 / 衰竭区 |
| 突破效率阈值 | 5.0 | 效率高于该值视为放量突破 |
| 低效（震荡）阈值 | 0.5 | 效率低于该值视为高换手震荡 |

### 信号过滤（信号稀疏化核心）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 信号仅在 K 线收盘确认 | ✅ | 实时 K 线中的信号要等收盘才出现与触发警报，避免盘中重绘反复闪烁 |
| 同类信号冷却（根 K 线） | 20 | 同一类信号触发后 N 根内不再重复触发，抑制连续噪音；0 表示不限制 |
| 背离枢轴左半宽 | 5 | 枢轴高 / 低点左侧需有多少根 K 线 |
| 背离枢轴右半宽 | 5 | 枢轴高 / 低点右侧需有多少根 K 线确认；越大信号越可靠、确认延迟也越大 |
| 背离最小摆动幅度（ATR） | 0.25 | 新枢轴相对前枢轴至少达到该倍 ATR 才视为有效新高 / 新低，过滤微小波动；0 表示不限制 |

### 风格与级别过滤（依据 A 股回测）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 波动率风格过滤 | ✅ | 回测显示背离在低波动慢牛（如银行）上失效、在高波动成长股上有效；开启后低波动标的的吸筹与背离信号被抑制 |
| 最小波动率（ATR/收盘价 %） | 0.4 | 15 分钟尺度建议 0.4，1 小时 0.8，5 分钟 0.25；低于该值的标的信号被过滤 |
| 更高周期（HTF）过滤 | ✅ | 回测显示 1 小时级别方向确认质量最高；开启后要求上一根已完成的 HTF Z 分数不过热 / 不过冷 |
| 更高周期 | 60 | 15 分钟图建议 60，1 小时图建议 240 或 D；可选 15/30/60/120/240/D |
| HTF 过滤阈值（±） | 0.5 | 底背离要求 HTF Z ≤ +0.5（大级别不过热）；顶背离要求 HTF Z ≥ -0.5（大级别不过冷） |

### 仪表盘

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 显示仪表盘 | ✅ | 4 列 × 6 行状态表 |
| 仪表盘位置 | 中左 | 左上 / 右上 / 中左 / 中中 / 中右 / 左下 / 右下 |
| 仪表盘字号 | 小 | 极小 / 小 / 中 |

### 仪表盘名词解释

仪表盘为 **4 列 × 6 行**状态表：第 1 列状态点、第 2 列方向图标、第 3 列数值 / 标签、第 4 列指标名称。

| 行 | 指标 | 图标与含义 |
| --- | --- | --- |
| 第 1 行 | Z 分数 | ▲ 偏多（> 0）／▼ 偏空（< 0），数值越大买盘越强；状态点 ● 红色 = 极限超买（> +2）、绿色 = 极限超卖（< -2）、无点 = 常规区间 |
| 第 2 行 | 效率 | ◆ 突破 = 资金驱动的有效行情（效率 > 5）；◇ 低效 = 高换手震荡、价格难有实质推进（效率 < 0.5）；— 均衡 = 正常状态 |
| 第 3 行 | 阶段 | ● 吸筹 = CVD 上升 + 价格横盘，疑似主力低位吸筹；! 衰竭 = Z 分数处于极限区，行情可能过热或超卖；— 中性 = 无特殊状态 |
| 第 4 行 | 背离 | ▼ 顶背离 = 枢轴新高但 CVD 未跟上（看空反转前兆）；▲ 底背离 = 枢轴新低但 CVD 未走低（看多反转前兆）；— 无背离 |
| 第 5 行 | 过滤 | ✓ 可通过 = 波动率与更高周期过滤均满足，信号可用；✗ 已过滤 = 当前被波动率或更高周期过滤抑制，即使出现背离也不触发信号 |

> 背离基于枢轴确认，存在若干根 K 线的确认延迟，参考价值高于效率与阶段两行。

## 🧭 使用建议

1. **周期选择**：综合 A 股多元回测结论，**主用 15 分钟或 1 小时**；5 分钟噪音大、成本高，仅适合高波动成长类标的长线观察；
2. **动量确认**：Z 分数上穿 0 线（动量转多）、下穿 0 线（动量转空），可作为多空倾向的过滤条件；
3. **过滤器**：仪表盘第 5 行显示“可通过 / 已过滤”——低波动标的（如银行）或大级别过热/过冷时信号被抑制，属预期行为；确需在低波动标的上使用可关闭“波动率风格过滤”；
4. **极端区**：进入 ±2 以上极端区出现衰竭信号时，谨慎追单、留意反转；但强趋势中行情可能长期停留在极端区，不要机械反向操作；
5. **参数微调**：建议从默认值开始，每次只改一项；信号仍偏多时可调大“同类信号冷却”，或调大背离枢轴半宽与“最小摆动幅度”；切换周期时同步调整“最小波动率”与“更高周期”。

## ⚠️ 注意事项

1. **重绘风险**：本指标使用当前未收盘 K 线实时计算，Z 分数曲线会随 tick 变化；但**信号默认已在 K 线收盘后确认**（可在“信号过滤”中关闭），未收盘 K 线不会触发信号与警报；
2. **只比较 Z 分数**：CVD 是累计量，不同标的、不同起始时间的量级不同，不要比较原始数值；图表起始时间不同，Z 分数也会有差异；
3. **信号非买卖点**：吸筹与背离是观察性信号，虽已稀疏化并加过滤仍可能有误报，需结合价格行为综合判断；背离信号在枢轴右半宽确认后才会出现，存在若干根 K 线的确认延迟；
4. **HTF 过滤说明**：更高周期 Z 分数采用 Elder 累积/派发线口径（自包含表达式），取上一根已完成值，无未来函数，但会随 HTF K 线形成过程更新；
5. **默认阈值按 15 分钟校准**：效率阈值与“最小波动率（0.4%）”偏向 15 分钟尺度，切换周期或标的风格时请按需调整；
