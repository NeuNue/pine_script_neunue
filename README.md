# Key Level Finder

本 Pine 脚本由 NeuNue 开发，主要基于 QQQ 进行开发和校准。目标是帮助观察美股大盘股与高流动性 ETF 的支撑、阻力，以及价格容易反复争夺的区域。

> 本脚本适合基于关键价位进行回踩后右侧交易的交易者。绝不适用于以本脚本所绘制的关键价位有效作为预设，然后提前在支撑位进行限价挂单抄底左侧交易的人。

脚本固定使用 1 小时常规交易时段 K 线，仅支持 1 小时及以下图表周期。它会回看价格反复停留、明显拒绝、放量和留下跳空缺口的位置，再按照各项权重计算，并把统计上相近的价位合并为关键价位区间。

该脚本适用于 SPY、QQQ、SOXX，以及 AAPL、MSFT、NVDA 等成交活跃的大盘股。对小盘股、低流动性标的、外汇、加密货币或全天交易期货的适配度较低，直接套用时，结果可能不完全符合其实际市场行为。建议按需要调整权重分配

## 权重值分别表示什么？

### 1. 触及与拒绝（默认40）

可以理解为“这个位置以前到底有没有被机构资金防守过”。价格多次到这里就反弹或回落，或者留下明显长影线，这一项计算的分值就会增加。

如果图上总出现只反应过一次的杂乱价位，也可以提高这一项，或者同时提高“最低强度”。

### 2. 多空转换（默认20）

关注“原来的阻力突破后变成支撑”以及“原来的支撑跌破后变成阻力”。

如果你主要做突破、回踩和趋势延续，可以提高这一项；如果标的长期横盘，很少走出有效突破，可以适当降低。

### 3. 相对成交量（默认20）

关注关键位置形成时，参与交易的人是不是明显比平时多。放量意味着更多资金在这里达成过共识。成交量稳定、流动性好的大盘股可以保持默认值。

如果财报、指数调仓经常制造一次性的放量，可以适当降低，避免单根K线对结果影响过大。

### 4. 缺口（默认10）

关注开盘跳空后留下的上下边界。盘前、盘后的财报或消息面导致的跳空经常会成为后续支撑、阻力或回补目标。

交易经常跳空的成长股、半导体股时可以提高；走势平稳、很少出现有效缺口的ETF或大盘股可以降低。

### 5. 整数共振（默认10）

关注700、705、710这类容易被交易者记住和挂单的整数位置。

如果标的经常围绕5美元或10美元整数位反应，可以提高；如果画出的区间过度集中在整数位，却没有明显历史反应，就应该降低。

## 怎么调整比较稳妥

- 权重并非最佳值。对于同一标的不同的行情，最佳的权重值也不一样。
- 这些数字表示相对权重，不要求加起来等于100。全部同时乘以两倍不会改变结果；把某项设为0，才表示完全不考虑这一类证据。
- 建议从默认值开始，每次只改一项，每次调整5—10点。先观察误判或漏判属于哪一类，再改对应权重，不要为了贴合一段历史一次性把所有参数都改掉。
- 杂乱弱位太多：提高“触及与拒绝”或“最低强度”。
- 突破回踩位经常漏掉：提高“多空转换”。
- 放量形成的价位不够突出：提高“相对成交量”。
- 财报或消息面导致的缺口边界不够突出：提高“缺口”。
- 整数位太多或太少：降低或提高“整数共振”。

## 三套参考配置适合什么标的

权重顺序：触及拒绝 / 多空转换 / 相对成交量 / 缺口 / 整数共振。

### 均衡型：40 / 20 / 20 / 10 / 10

默认配置，也是基于QQQ主要调教的配置。比较符合我自身主观交易中手动绘制的关键价位。

适合指数ETF，以及成交活跃、走势相对连续的大盘科技股。适合作为盘中观察和波段交易的参考。

### 传统支撑阻力型：50 / 25 / 15 / 5 / 5

更相信反复触及和突破回踩，弱化一次性放量、缺口及整数位。

适合走势较稳定、历史价位反复有效的SPY、指数ETF、成熟大盘股，以及偏区间或均值回归的交易方式。

### 事件与缺口型：30 / 15 / 25 / 20 / 10

更重视放量和跳空。适合财报反应明显、消息驱动较强且流动性充足的成长型大盘股和热门股。

它不建议用于成交稀疏的小盘消息股，因为异常成交量和滑点会让历史结果看起来比实际可交易性更好。

## 数据仅供参考，不适用于实时交易，不构成投资建议

本脚本会读取当前尚未收盘的1小时K线，所以当前小时内的区间和强弱可能随着价格、影线及成交量变化。属于部分实时重绘；1小时K线收盘以后，由这根K线产生的指标才会确定下来。

中枢价位的高低区间还需要后面几根K线来辅助确认。确认以后，区间会从原枢轴发生的时间开始重绘，因此回看图表时可能看起来像是它当时就已经出现，实际上实时交易中要等确认K线结束后才能知道。

脚本没有使用lookahead_on读取未来数据，但仍不建议当作历史进场信号进行回测。

实时交易时，更适合把它当作支撑阻力地图：以已经收盘并确认的1小时区间为主，再结合5min K线所展示的价格行为决定是否进场。

不要仅凭当前小时内刚出现或分数正在变化的区间自动下单。它既能辅助实时观察，也能用于回溯研究，但不是量化交易工具。
